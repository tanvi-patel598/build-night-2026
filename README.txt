TRUSTMATCH WEBSITE PROTOTYPE

Open index.html in a modern browser. No installation or server is required.

Included working interactions:
- Navigation between Home, Trust Check, Preferences, and Matches
- Five-question self-reflection questionnaire with required-answer validation
- Clear disclaimer that the questionnaire cannot prove honesty or reliability
- Demo verification status selector
- Preference form with consent checkbox and clear form button
- Sample matching cards and illustrative compatibility calculation based on shared hobbies, values, and lifestyle
- Responsive layout for desktop and mobile

Important limitations:
- This is a front-end prototype only. It has no backend, user accounts, real identity checks, secure storage, messaging, or database.
- Preference data is held in page memory only and is not sent to a server.
- Sample profiles are fictional.
- The verification selector is self-reported and is not actual verification.
- Personality/self-reflection answers are not a lie detector and must not be presented as proof of trustworthiness.

Before launch: add a secure backend, authentication, consent-based identity verification through a reputable provider, data minimization and deletion, moderation/reporting, privacy policy, accessibility and security testing, and legal review for the countries where it will operate.
